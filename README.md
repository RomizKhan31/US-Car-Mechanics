# 🚗 US Car Mechanics

A modern and responsive automotive service website designed for car repair, maintenance, diagnostics, and customer service.

🔗 **Live Demo:** https://jolly-meringue-d0d152.netlify.app/

---

## ✨ Features

* Modern automotive-focused UI
* Responsive design for desktop, tablet, and mobile
* Interactive hero image slider
* Automotive services showcase
* Service booking modal
* Video presentation modal
* Recent works section
* Customer testimonials
* FAQ section
* Contact section
* Responsive navigation menu
* Smooth animations and interactions

---

## 🛠️ Tech Stack

* **React 19**
* **TypeScript**
* **Vite**
* **Tailwind CSS**
* **Motion**
* **Lucide React**

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/RomizKhan31/US-Car-Mechanics.git
```

### Navigate to the Project

```bash
cd US-Car-Mechanics
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```

---

## 🏗️ Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
